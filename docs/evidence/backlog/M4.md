# M4: explicit typed initializers

Backlog item M4 (P1), stage B. Date: 2026-10-06. Base: `ba60bf5` (C1 owner decisions).
This is a public API and contract addition, recorded here as `AGENTS.md` rule 5 requires.
**The default is unchanged:** constructors still zero-initialize, and initializers are
opt-in. Golden dumps, frozen checksums and existing tests are therefore unaffected.
(Not to be confused with milestone M4, [../M4.md](../M4.md).)

## Problem

Zero initialization trains a single linear-in-coefficients layer but not a deep network.
With all coefficients zero, every hidden unit of a layer receives the same constant input
and the same gradient. The last layer can only fit the target mean, after which every
coefficient gradient `Σ_b u_b φ_k(const)` is zero: an exact saddle (measured below). Safe
rational policies add a second stationary point, `b = 0` (M2 evidence), so their
denominators must start nonzero.

## Change

`include/kan/initializers.hpp`, `src/initializers.cpp`, `src/init/{portable_math.hpp,moments.hpp,moments.cpp}`:

```cpp
enum class Distribution { Uniform, Normal };
```

### Decisions

- **Typed variant plus free functions,** as in R1 and `kan/families.hpp`. There are no
  string options. Initializers commit through `Layer::set_carrier`, so a failure leaves the
  layer unchanged. The network form initializes copies and assigns the network only after
  every layer has succeeded.
- **Per-term variance split.** With independent zero-mean coefficients,
  `E_c E_x[y²] = Σ_i Σ_k σ_k² m_k` has no cross terms for *any* input measure, orthogonal or
  not. Setting `σ_k² = gain²·Var_ref/(I·K·m_k)` gives every term an equal share. A single
  σ for all terms would leave physicists' Hermite edges dominated by `H_{K-1}`, since
  `m_k = 2^k k!`.
- **Target `E[y²] = gain²·Var_ref`:** the output second moment equals the variance of the
  input measure. This is the literal meaning of "variance-preserving", and it keeps a stack
  of one family self-consistent.
- **Reference measures:**
  - polynomial families use their orthogonality measure, which gives exact closed forms
    (table in the contract);
  - B-splines use the uniform measure on their domain;
  - RBFs and Mexican hats use the uniform measure on their center range;
  - rational edges use z uniform on `[-R, R]`.

  No user-selectable measure was added (YAGNI). A different input distribution is handled
  by an input map (M1).
- **Rational numerator moments are per edge.** They use the edge's own drawn denominator,
  `μ_k = E[u^{2k}/Q(Ru)²]`, by quadrature. This is exact variance preservation, not a
  `Q ≈ 1` approximation. Its cost is 128 nodes per edge, a one-off.
- **Portability.** The PRNG is SplitMix64. The transform is a polar method with a
  logarithm built from IEEE basic operations. Moments are computed by Gauss–Legendre
  quadrature whose nodes are found by bisection on the Legendre recurrence. Trainable
  widths use a Cody–Waite exponential. Everything uses only `+ - * /`, `sqrt`, `frexp`,
  `ldexp` and `nearbyint`. `std::log`/`std::exp`/`std::cos` and `std::normal_distribution`
  are implementation-defined and are not used for parameters.
- **Bias** is set to zero. **Trainable RBF centers and log widths are kept:** they are the
  user's layout and define the reference measure. **LayerNorm** maps with gain/bias are
  reset to the standard gain 1, bias 0. Fixed maps are untouched.
- **Python** is bound in a separate `python/initializer_bindings.cpp`, which
  `python/bindings.cpp` calls in two lines. This keeps the edit localized next to the
  concurrent C9 work.

### pykan comparison (master `ecde4ec`, `kan/KANLayer.py`, `kan/MultKAN.py`)

pykan does:

```python
noises = (torch.rand(num+1, in_dim, out_dim) - 1/2) * noise_scale / num
coef = curve2coef(grid_points, noises, grid, k)
scale_sp = 1/sqrt(in_dim)
scale_base = mu/sqrt(in_dim) + sigma*U(-1,1)/sqrt(in_dim)  # SiLU base branch
```

The `MultKAN` default is `noise_scale = 0.3`. The noise is **uniform**, not Gaussian; the
backlog wording "Gaussian" is inaccurate. `NoiseInit` matches pykan in:

- the distribution, `U(-a/2, a/2)`;
- the amplitude `a = scale/(G·√in)`, with `scale_sp` folded in and `G` the grid intervals;
- the default scale.

`Normal` is an equal-variance alternative. Documented differences:

1. The noise is placed on the coefficients, not on the G+1 grid values followed by a
   least-squares fit. For B-splines, coefficient noise and value noise have the same
   order, because of the partition of unity.
2. There is no SiLU base branch, which is backlog M3. Measured consequence: deep NoiseInit
   networks propagate almost no signal (table below). pykan's depth relies on that branch.
3. The generator is SplitMix64 rather than torch's. Bitwise equality with pykan is
   impossible in any case.
4. `G` for non-spline families is a convention: the term count, or m+1 for rational
   numerators.

### Pole-freedom proof (rational)

`|β_k| ∈ [ρ/2n, ρ/n]` and `b_k = β_k/R^k`. For `|z| ≤ R`:
`|S(z)| ≤ Σ|b_k||z|^k ≤ Σ|β_k| ≤ ρ`. Then:

- **Guarded:** `Q ≥ 1-ρ`. The guard needs `|Q| > ε(1+Σ|b_k z^k|)`, and the right-hand side is
  at most `ε(1+ρ)`. Validation requires `ε(1+ρ) < 1-ρ`, otherwise `invalid_argument`, so
  the guard cannot fire on the domain. With the default ρ = 0.5 this needs ε < 1/3; the
  default ε is 1e-8. The FP32 threshold `max(ε, n·2⁻²³) ≤ 2e-6` holds as well.
- **Absolute:** `Q ∈ [1, 1+ρ]`.
- **Smooth:** `Q ∈ [1, 1+ρ²]`.
- **Not stationary:** every `b_k` is nonzero, so neither safe policy starts at the
  stationary point `b = 0`.

The test `rational_denominators_are_bounded_nonzero_and_pole_free` checks the bound
exactly. It covers the three policies × n ∈ {1, 2, 5, 16} × R ∈ {1, 0.25, 3} × both
initializers. It runs backward over 801 points spanning the whole domain with no
`domain_error`, and checks that the denominator gradients are nonzero.

`v = 1/2`. Deep polynomial stacks therefore need input maps, as the contract states.

### Demonstration (`tests/initializer_training_test.cpp`, CPU, deterministic)

Setup:

- target `f(x₁, x₂) = x₁x₂` on an 8×8 grid in `[-0.9, 0.9]²`, which is not of the form
  `g(h₁(x₁)+h₂(x₂))`;
- network `[Tanh, KAN 2→8, (Tanh, KAN 8→8)×3, Tanh, KAN 8→1]`, five KAN layers;
- full-batch SGD on the MSE, rate 0.03, 3000 epochs, seed 1, Uniform distribution;
- target variance 0.1205.

## Default decision and recommendation

The constructor default stays zero, as the brief requires and as golden/bit-identity
preservation needs. **Recommendation, not applied:** keep the zero default in the
constructors, which are value-typed and deterministic without a seed. Instead, document
`kan::initialize(net, VarianceScaling{...})` as the standard training entry point. A future
breaking change could make a seeded `VarianceScaling` the default of a training-oriented
factory. Changing constructor semantics would invalidate every golden dump and would hide a
seed choice. This is left to the owner.

## Open points

- **M3 (SiLU residual branch):** NoiseInit becomes pykan-equivalent in depth only with it.
  `scale_base` would then be initialized as pykan's `mu/√in + sigma·U(-1,1)/√in`.
- **M5 (normalized Hermite):** this would remove the need for 2^k k! scaling.
- The training demonstration takes about 65 s in Release; its CTest timeout is 900 s.
