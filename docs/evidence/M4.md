## Delivered behavior

- Distinct typed rational Layer constructor, independently selected numerator
  and denominator degrees0..16, per-edge trainable a/b parameters and fixed Q(0)=1.
  This is a Padé-compatible parameterization, with no automatic Taylor fitting.
  Rational functions are not represented as fixed linear basis expansions.
- Explicit center/positive scale, Horner evaluation and relative denominator
  cancellation guard. Unsafe samples, including removable poles, fail explicitly;
  no clipping changes the learned function. Nonfinite intermediates/results fail.
- Analytic input, numerator, denominator and bias VJPs; rare log-space recovery
  of representable derivatives after intermediate underflow; mixed networks,
  atomic setters and whole-network SGD. Coefficient L2 penalizes numerators only.
- One private fixed-array CPU evaluator shared by public owned-vector evaluation
  and Layer contraction, eliminating per-edge/sample heap storage.
- Persistent CUDA forward/backward/SGD and learned snapshots, mixed basis/rational
  chains, pole/overflow invalidation and recovery, unchanged construction-time
  device allocations, warp-parallel parameter reduction with bounded launch tails.
- Strict NumPy interfaces, owned snapshots, zero-order shapes, installed C++/CUDA
  and Python use, deterministic nonlinear learning with independent holdout.

## Matched performance and practical limits

Frozen degrees6/4,64->64->32->16,batch1024,double training calls:

- Balanced GPU resident median **29.951->20.780ms**, reduction **30.62%**;
  transfer-inclusive **28.804->20.885ms**, reduction **27.49%**. Four isolated
  baseline/final/final/baseline runs yield14samples per source/mode. All final
  VJPs/parameters verify within3.469e-18, with exact untimed evolving replay.
- Balanced CPU complete-call median **4613.84455->1521.9724ms**, reduction
  **67.0129%**. Allocations fall **40894504->40** per complete network call;
  cumulative allocated bytes1804788788->5432372. Six samples per source; all
  **392416** final output/VJP/learned-parameter doubles are bit-identical.

Each optimization has its own frozen sources and fixtures. One CPU timing
sequence overlapped a build/sweep and was discarded before a clean isolated
replay. Broad numerical-sweep timings remain diagnostic and imply no additional
performance claim. Nsight Systems identifies the GPU parameter reduction cost
falling470.591->240.786ms over81calls. Nsight Compute counters remain denied
(`ERR_NVGPUCTRPERM`); maximum occupancy/bandwidth saturation is unmeasured.
Neither speedup is a claim about arbitrary models or other hardware.

The guard protects executed samples, not an entire continuous input domain.
Finite SGD candidates may therefore fail their next execution. No pole-free
parameterization, denominator penalty, Taylor-series solver, serialization,
quantum implementation or expanded distribution work is introduced here.
