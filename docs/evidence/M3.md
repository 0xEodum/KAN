## Delivered behavior

- Explicit clamped B-splines (degree0..16), knot/multiplicity/domain validation,
  analytic input derivatives, exact endpoint conventions and outside-domain zeros.
- L2-normalized continuous Mexican-hat wavelets with explicit positive scales and
  translations, analytic input derivatives and representable extreme-tail handling.
- Opt-in shared Gaussian centers/log widths, analytic nonlinear VJPs, setters and
  atomic layer/network SGD with exponentiated-width overflow/underflow validation.
  Legacy fixed scalar-width Gaussian behavior remains available.
- Exact spline knot insertion and deterministic sample-driven refinement transform
  all edge coefficients while preserving functions/derivatives within tolerance.
  Explicit indexed network refinement and stale gradient-shape rejection.
- Explicit coefficient L2 objective/VJP, unpenalized bias/nonlinear parameters,
  and optional resident backward L2 added on the GPU.
- Resident execution of all eight families with persistent nonlinear parameters,
  derivatives/reduction workspaces, learned snapshots and whole-network atomic SGD.
  Grid changes are explicit CPU snapshot/refine/executor-reconstruction setup.
- Strict NumPy bindings, owned configuration/gradient snapshots and localized
  independent-holdout learning. CPU C++ retains no CUDA/Python runtime dependency.

## Profiling and measured performance

[M3-benchmark.md](M3-benchmark.md) records raw samples, frozen inputs, exact
source/binary provenance, matched-call verification and profiler exports.
Nsight Systems identified a seven-thread shared-RBF VJP using99.8% of measured
kernel time. Parallel tiled partial sums and a fixed-order finish reduce that
bottleneck; persistent scratch uses the configured batch/edge tile capacity.
The final profile assigns38.0% to both nonlinear reduction kernels combined.

For the frozen seven-term trainable-RBF64->64->32->16, batch1024 case, balanced
complete resident training medians are **1222.545ms before /4.501ms after**;
transfer-inclusive medians **1220.214ms /6.620ms**. Each version/mode pools14samples
from balanced preopt/final/final/preopt runs, with all VJPs, learned parameters
and evolving trajectories verified. This accepts the scoped GPU reduction change.

Broad sweep variance is substantial under WDDM, including resident cases with
IQRs exceeding their medians. Preserve those observations and do not infer general
throughput or other-library speedups. Nsight Compute counters remain denied
(`ERR_NVGPUCTRPERM`), so full occupancy/bandwidth saturation is unmeasured.
The performance gate resolves a measured bottleneck; it does not certify maximum
utilization for every possible topology, basis size or hardware.
